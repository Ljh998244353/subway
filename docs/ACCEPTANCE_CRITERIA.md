## 2. 一期功能验收标准

| 模块 | 验收标准 |
| --- | --- |
| 运营总览 | 显示场内人数、累计客流、楼层状态、趋势和拥挤预警；支持加载、空态、错误态 |
| 店铺分析 | 显示进店、停留、转化、评分、排名和低效原因；评分规则可解释 |
| 低效预警 | 支持低评分、低转化、连续下滑、数据异常预警；有等级和处理状态 |
| 数字孪生 | 使用自绘楼层图展示楼层、店铺、热力和告警；支持楼层切换和店铺点击 |
| 客群画像 | 仅展示匿名聚合统计；不出现身份、人脸或个人轨迹 |
| API | 使用 `/api/v1`；OpenAPI 与实现一致；错误码覆盖 400/401/403/404/409/422/500 |
| AI 事件 | 输出事件有稳定 ID、时间、来源、模型版本、阈值和审计字段 |
