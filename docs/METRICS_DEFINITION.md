# 指标定义

更新时间：2026-05-10

## 1. 通用口径

| 项目 | 规则 |
| --- | --- |
| 时间 | 后端内部使用 UTC；前端展示按配置时区转换 |
| 粒度 | 默认支持 5 分钟、小时、日维度 |
| 幂等 | 所有事件必须有稳定事件 ID 或幂等键 |
| 来源 | Mock、合成、AI 输出、人工导入都必须标记来源 |
| 统计边界 | 按商场、楼层、店铺、业态和时间窗口聚合 |

## 2. 客流指标

| 指标 | 定义 | 计算方式 | 备注 |
| --- | --- | --- | --- |
| 当前场内人数 | 当前时间估算在场人数 | 进入人数累计 - 离开人数累计，按校准规则修正 | 不允许长期为负 |
| 今日累计客流 | 当日进入商场的人次 | 当日入口进入事件计数 | 需处理重复事件 |
| 楼层客流 | 指定楼层时间窗口内通过或停留人次 | 楼层 ROI 或线段事件聚合 | 可按小时展示 |
| 峰值客流 | 时间窗口内最高场内人数 | max(场内人数时间序列) | 用于拥挤判断 |
| 拥挤指数 | 当前客流相对阈值的比例 | 当前人数 / 楼层或区域阈值 | 阈值可配置 |

## 3. 店铺指标

| 指标 | 定义 | 计算方式 | 备注 |
| --- | --- | --- | --- |
| 曝光客流 | 店铺门前或相关 ROI 经过人数 | 店铺外 ROI 经过事件计数 | 用于转化分母 |
| 进店人数 | 进入店铺 ROI 的人次 | 入店线段正向事件计数 | 去重规则后续细化 |
| 出店人数 | 离开店铺 ROI 的人次 | 出店线段反向事件计数 | 不得大于合理累计值 |
| 店内人数 | 店铺内估算人数 | 进店累计 - 出店累计 | 负数需校准 |
| 平均停留时长 | 店铺访问会话平均持续时间 | sum(离店时间 - 入店时间) / 会话数 | 小于 0 视为数据异常 |
| 进店转化率 | 曝光客流转化为进店的比例 | 进店人数 / 曝光客流 * 100% | 范围 0-100% |

## 4. 评分指标

店铺经营评分范围为 0-100。P0 定义草案如下，后续 P7 实现时必须测试边界。

```text
店铺评分 = 客流得分 * 0.30 + 转化得分 * 0.30 + 停留得分 * 0.20 + 趋势得分 * 0.20
```

| 等级 | 分数范围 | 含义 |
| --- | --- | --- |
| A | 85-100 | 表现优秀 |
| B | 70-84 | 表现稳定 |
| C | 55-69 | 需要关注 |
| D | 0-54 | 低效预警 |

## 5. 告警指标

| 告警 | 触发规则草案 | 级别 |
| --- | --- | --- |
| 高客流低转化 | 曝光客流高于同业态 P75，转化率低于 P25 | 中 |
| 连续下滑 | 店铺评分连续 3 个统计周期下降 | 中 |
| D 级店铺 | 店铺评分小于 55 | 高 |
| 拥挤告警 | 拥挤指数大于 1.0 持续超过阈值 | 高 |
| 数据异常 | 负人数、转化率越界、重复事件异常增多 | 高 |

## 6. 数据质量规则

```text
进店人数不能为负
出店人数不能大于合理累计值
店内人数不能长期为负
转化率必须在 0 到 100%
评分必须在 0 到 100
停留时长不能小于 0
热力坐标必须在楼层范围内
同一事件不能重复消费
跨天统计必须按营业日边界处理
营业时间边界必须可配置
```
